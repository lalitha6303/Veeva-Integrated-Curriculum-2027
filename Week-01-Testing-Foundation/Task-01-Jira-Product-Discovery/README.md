# Task 01 – SmartCart Product Discovery Using Jira

## Project Overview

**Project Name:** SmartCart Product Discovery  
**Platform:** Jira Product Discovery and Jira Software  
**Project Type:** Product Discovery and Delivery Management  
**Task:** 01

## Objective

To understand and implement the product discovery workflow using Jira by managing product ideas, collecting insights, prioritizing features, planning roadmaps, and connecting selected ideas to software development work items.

## Practical Implementation

The following activities were completed:

### 1. Project Setup
- Created a Jira Product Discovery project named SmartCart Product Discovery.
- Explored the project settings and idea management features.

### 2. Idea Management
Created and managed five sample product ideas:
- New Rewards Program
- Express Checkout
- Improve Waiting List Experience
- Refactor User Profile Data
- Explore VR Travel Features

### 3. RICE Prioritization
- Configured Reach, Impact, Confidence and Effort fields.
- Created a custom RICE score formula.
- Calculated and verified scores for all five ideas.
- Sorted ideas based on RICE score.

**Formula:**

RICE Score = (Reach × Impact × Confidence) / Effort

### 4. Views and Visualization
Created and configured the following views:

| View | Purpose |
|---|---|
| Prioritized Backlog | Rank ideas using RICE scores |
| Impact vs Effort Matrix | Compare impact and development effort |
| Triage Inbox | Identify ideas awaiting review |
| SmartCart Roadmap | Visualize planned idea timelines |

### 5. Idea Details and Insights
- Explored Hypothesis, Validation and Decision sections.
- Examined sample customer insights from Pendo and Slack.
- Understood how research evidence supports product decisions.

### 6. Jira Delivery Management
Created a separate Jira Software project named SmartCart Development.

- Created Epic: **SD-1 – Implement Rewards Program**
- Linked the Epic to the New Rewards Program idea (SPD-2).
- Created a Story directly from the product idea.
- Created Story: **SD-2 – Implement Reward Points for Customer Bookings**
- Verified the Story's Parent field is linked to Epic SD-1.
