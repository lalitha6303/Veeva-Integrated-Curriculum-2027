# Week 1: Testing Foundation 
## Focus
The focus of Week 1 was to understand software development and testing fundamentals, including the Software Development Life Cycle (SDLC), software testing concepts, and different software development methodologies.

## Topics Covered

### 1. Software Development Life Cycle (SDLC)
- Introduction to SDLC and its importance in software development.
- Understanding the different stages of SDLC:
  - Requirement Gathering and Analysis
  - System Design
  - Coding and Implementation
  - Testing
  - Deployment
  - Maintenance

### 2. Software Development Methodologies
- Understanding the Waterfall Model and its sequential development approach.
- Understanding the Agile Model and its iterative and incremental approach.
- Differences between Agile and Waterfall methodologies.
- Learning the Agile development process, including:
  - Sprint Planning
  - Requirement Analysis
  - Development
  - Testing
  - Sprint Review
  - Retrospective
- Understanding how Agile teams collaborate and deliver software incrementally.

## Key Learnings
- Gained an understanding of the complete SDLC process and the purpose of each development stage.
- Learned how software moves from requirement gathering to deployment.
- Understood the differences between Agile and Waterfall development methodologies.
- Learned how the Agile model works through iterative development, sprints, continuous feedback, and collaboration.
- Understood the importance of testing in delivering reliable and quality software.

## Outcome
Built a strong foundation in software development life cycle concepts, Agile methodologies, and software testing fundamentals, preparing for practical implementation in subsequent weeks.
