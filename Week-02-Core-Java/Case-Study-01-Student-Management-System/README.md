# Case Study 01 – Student Management System

## Overview
A Java-based Student Management System that maintains student records using file handling.

## Student Attributes
- Roll Number
- Age
- Name
- Marks (M1, M2, M3, M4, M5)
- Grade

## Operations Implemented
- Add Student
- Read / Display Student Records
- Update Student Details
- Delete Student Records

## Concepts Used
- Java Classes and Objects
- Packages
- Methods
- File Handling
- BufferedReader and BufferedWriter
- Exception Handling
- CRUD Operations

## Technologies Used
- Java
- Eclipse IDE

## Storage
Student records are maintained in `student.txt`.

## Objective
To understand Java file handling and implement CRUD operations using a modular programming approach.
