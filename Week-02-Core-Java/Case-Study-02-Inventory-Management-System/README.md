# Case Study 02 – Inventory Management System

## Overview
A menu-driven Java application that manages product information and inventory quantities using object-oriented programming.

## Product Attributes
- Product ID
- Product Name
- Quantity
- Price

## Operations Implemented
- Add Product
- Remove Product
- Check Product Details
- Display All Products
- Exit Application

## Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- ArrayList
- Loops and Switch Statements
- Methods
- Scanner for User Input

## Project Structure
- `Product.java` – Stores product information.
- `Inventory.java` – Implements inventory operations.
- `InventoryManagement.java` – Handles the menu and user interaction.

## Technologies Used
- Java
- Eclipse IDE

## Storage
Product details are maintained in an ArrayList during program execution. No file or database persistence is used.

## Objective
To apply object-oriented programming and Java Collections by developing a modular inventory management application.
